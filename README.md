# 🤖 AI Daily Digest Bot

An automated bot that fetches top AI News, Python Jobs & Internships daily and summarizes them using OpenAI.

Built for OpenAI Skills Studio x Handshake Challenge

## 🚀 Demo Video
Watch here: https://loom.com/ (Loom record chesaka link marchu)

## ✨ Features
- Fetches AI news, Python jobs daily
- Summarizes using GPT-4o-mini
- Saves 1 hour daily

## 🛠️ Tech Stack
Python, OpenAI API, Feedparser

## 📦 How to Run
pip install -r requirements.txt
python main.py
